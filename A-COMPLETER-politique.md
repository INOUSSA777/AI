# Politique de confidentialité INO-Education — à finaliser

## Où mettre le fichier
Place `politique-confidentialite.html` dans ton dossier `web/`, puis :
    git add -A
    git commit -m "Ajout politique de confidentialite"
    git push
Elle sera accessible à :
    https://inous-ai.onrender.com/politique-confidentialite.html
C'est cette URL que tu colleras dans la Play Console.

## 4 champs à remplacer dans le HTML (surlignés en doré)
- [DATE — ex. 15 août 2026]
- [NOM / RAISON SOCIALE DE L'ÉDITEUR]
- [ADRESSE / VILLE, PAYS]   → ex. « Ouagadougou, Burkina Faso »
- [TON-EMAIL-DE-CONTACT]    → une adresse réelle (apparaît 4 fois)

Astuce : Rechercher/Remplacer sur chaque crochet [ ].
